# MIDI 音符动作

## 简介

MyKeymap 可以把某个按键变成 **MIDI 音符**：按住时向虚拟 MIDI 端口发送 NoteOn（`0x90`），松开时发送 NoteOff（`0x80`）。这样 MyKeymap 就相当于一台 MIDI 输入设备，可以用来弹奏软音源、触发 DAW、控制灯光/视觉软件等。

- 演奏模型：**按住发声、松开停声**。
- 每个按键可独立设置「音符号 / MIDI 通道 / 力度」。

## 前置准备：安装 loopMIDI 并创建虚拟 MIDI 端口

MyKeymap 只负责「发送」MIDI 消息，因此本机需要一个 MIDI 端口来接收并转发给目标软件。**这些端口必须由 loopMIDI 创建并保持运行**，MyKeymap 不会自动创建端口：

1. 安装虚拟 MIDI 端口工具（推荐 loopMIDI）。本仓库 [`tools/loopMIDI.exe`](tools/loopMIDI.exe:1) 即该工具的安装包（已被 `.gitignore` 忽略，不进版本库）。
2. 安装并启动 loopMIDI。
3. 在 loopMIDI 界面点击左下角的 **「+」** 按钮，创建一个端口。**推荐直接命名为 `loopMIDI Port`**，与 MyKeymap 的默认端口名保持一致，这样设置里无需再填写端口名即可直接使用；当然也可自定义名称，此时在 MyKeymap 设置里填写的端口名需与之一致。
4. **保持 loopMIDI 处于运行状态**（可在其设置中勾选开机自启）。loopMIDI 退出后端口随之消失，MIDI 动作将不再生效。

## 配置步骤

1. 打开 MyKeymap 设置界面。
2. 在设置页的 **MIDI** 分区中填写虚拟 MIDI 端口名（例如 `loopMIDI Port`）。**该字段可以留空**：留空时后端会自动使用默认端口名 `loopMIDI Port`。若下拉为空，可直接手动输入端口名。
3. 进入按键映射界面，为某个按键选择动作类型 **🎹 MIDI 音符**。
4. 设置以下三个参数：
   - **音符号**：`C-1` 到 `G9`，共 128 个。
   - **MIDI 通道**：1–16。
   - **力度**：1–127（滑块）。
5. 保存后 MyKeymap 会重新生成脚本并生效。之后按住该键即可发声。

## 在 DAW / 软音源中接收

在目标软件中把该虚拟端口设为 MIDI **输入**：

- **DAW**（Reaper / Cubase / FL Studio 等）：在 MIDI 输入设备列表中启用 `loopMIDI Port`（或你自定义的端口名）。
- **独立软音源**：在音频/MIDI 设置中选择该端口作为输入。
- **灯光 / 视觉软件**：在 MIDI 输入中选择该端口，并把音符映射到对应触发。

## 音符号对照

音符号遵循 MIDI 标准，每个八度 12 个半音，`C-1 = 0`、`C4 = 60`、`G9 = 127`。

| 音名 | 音符号 | 说明 |
|---|---|---|
| C-1 | 0 | 最低音 |
| C0 | 12 | |
| C1 | 24 | |
| C2 | 36 | |
| C3 | 48 | |
| C4 | 60 | 常说的「中央 C」 |
| C5 | 72 | |
| C6 | 84 | |
| C7 | 96 | |
| C8 | 108 | |
| G9 | 127 | 最高音 |

音名使用升号制：`C C# D D# E F F# G G# A A# B`（例如 61 = `C#4`）。

## 注意事项与限制

- **仅支持键盘按键**：鼠标滚轮等没有 `up` 事件，无法可靠地发送 NoteOff，因此不适用于本动作。
- **端口必须由 loopMIDI 提供并保持运行**：MyKeymap 只会**精确匹配**设置里填写的端口名（忽略大小写），**不会自动创建端口，也不会回退到其它端口**。
- **未创建该端口时 MIDI 动作不生效**：端口名匹配不到（或 loopMIDI 未运行导致端口消失）时，MyKeymap 启动会弹出一条提示，告知需要去 loopMIDI 创建该端口；此时所有 MIDI 动作都不会发出声音。
- **端口名前缀按名称精确匹配**：名字写错不会被回退到别的端口，只会提示不可用，不会误从其它端口发声。
- **缩写模式不适用**：该动作在缩写映射中不可选（已 `hideInAbbr`）。
- **退出/重载保护**：退出或重新加载 MyKeymap 时会自动发送 All Notes Off（CC123）并关闭端口，避免残留卡音。

## 常见问题

- **设置页下拉没有端口**：确认 loopMIDI 已运行并至少创建了一个端口；仍未出现时，直接在输入框手动填写端口名（注意需与 loopMIDI 中的名称完全一致）。
- **启动时提示「未找到 MIDI 端口」**：说明 loopMIDI 未运行，或其中没有创建与设置一致的端口。请打开 loopMIDI 创建名为 `loopMIDI Port` 的端口（或与设置中填写的名称一致），并保持 loopMIDI 运行。
- **能配置但不发声**：检查目标软件是否已把该端口设为输入；确认音符号、力度不为 0；确认端口名与 loopMIDI 中的名称完全一致。
- **出现卡音**：多为退出前未收到 NoteOff。可重新触发一次同音，或重启 MyKeymap；程序已内置退出时的自动关音保护。
